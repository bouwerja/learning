# Tools in Software Development

Version Control

- Version control systems track changes in source code, recording who made changes and when, which is crucial for team collaboration and individual development.
- Git and GitHub are popular tools for managing code repositories, allowing branching and merging of code versions.

Libraries

- Libraries are collections of reusable code that provide specific functions or features, helping developers save time by not having to write code from scratch.
- Examples include jQuery for JavaScript DOM manipulation and Apache Commons Proper for reusable Java components.

Frameworks

- Frameworks provide a structured skeleton for building applications, dictating the architecture and workflow developers must follow.
- They enforce an "inversion of control," where the framework calls the developer's code, promoting standardization and efficiency; examples include AngularJS, Vue.js, and Django.

CI/CD Practices

- Continuous Integration (CI) automates frequent code integration and testing to ensure components work together smoothly.
- Continuous Delivery (CD) follows CI by deploying code changes to testing or staging environments automatically.

Build Tools and Automation

- Build tools compile source code into binaries, manage dependencies, and automate tasks like downloading dependencies, running tests, and deployment.
- Examples include Webpack (JavaScript bundler), Babel (JavaScript compiler), and Web Assembly (binary format for browsers).

Packages and Package Managers

- Packages bundle app files, installation instructions, and metadata, making installation simple and reliable for users.
- Package managers handle finding, installing, updating, and uninstalling software packages, managing dependencies and verifying package integrity.

Common Package Managers

- Platform-specific examples: DPKG and RPM for Linux, Chocolatey for Windows, Homebrew for MacOS.
- Language-specific examples: npm for Node.js, Maven and Gradle for Java, RubyGems for Ruby, Pip and Conda for Python.
