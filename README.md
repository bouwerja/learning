### 🟢 1. Go (`/golang`)
Focusing on clean architecture, strong typing, concurrency, and high-performance backend systems.
* **Key Topics:** Goroutines & Channels, Interfaces, Standard Library (`net/http`), Dependency Injection.
* **Frameworks & Tools:** Gin, Fiber, GORM, Docker, Makefiles.
* **Highlights:**
  * Custom HTTP microservices and REST APIs.
  * Concurrent data processors and worker pools.
  * CLI tools and database migration patterns.

---

### 🐍 2. Python (`/python`)
Exploring pythonic paradigms across data engineering, machine learning, web frameworks, and scripting.
* **Directory Structure:**
  * `📁 data-analysis/` — Interactive Jupyter Notebooks (`.ipynb`), Pandas data manipulation, NumPy arrays, and Matplotlib/Seaborn data visualizations.
  * `📁 django-projects/` — Full-featured MVC web applications with Django ORM, authentication, and REST framework (DRF) endpoints.
  * `📁 automation-scripts/` — Web scraping (BeautifulSoup/Selenium), file processing utilities, and API integrations.

---

### 🟢 3. Node.js (`/nodejs`)
Building event-driven, scalable backend architectures and RESTful microservices.
* **Key Topics:** Event Loop, Asynchronous I/O, Streams, Buffer Management, JWT Authentication.
* **Frameworks & Libraries:** Express.js, Fastify, Prisma ORM, Mongoose.
* **Highlights:**
  * Authentication workflows (OAuth2, Session/JWT).
  * WebSockets for real-time communication.
  * Middleware pattern implementation and REST API design.

---

### 🟡 4. JavaScript (`/js`)
Mastering core language mechanics, modern ES6+ features, and client-side interactions before/alongside frameworks.
* **Key Topics:** Promises, Async/Await, Closure, Prototypes, DOM Manipulation, Event Propagation, Fetch API.
* **Highlights:**
  * Vanilla JS mini-projects and custom UI widgets.
  * Algorithmic challenge solutions and data structures in JS.
  * Functional vs. Object-Oriented programming patterns in JS.

---

### 🐘 5. PHP (`/php`)
Understanding classic and modern web development using server-side scripting.
* **Key Topics:** OOP in PHP 8+, PSR Standards, PDO & Database Connections, Composer Dependency Management.
* **Frameworks:** Laravel / Symfony micro-components.
* **Highlights:**
  * Custom MVC framework built from scratch.
  * Form handling, validation, and session management.
  * Database CRUD operations with secure prepared statements.

## 🎯 Primary Goals & Learning Objectives

1. **Polyglot Fluency:** Understand the idiom, syntax, and best practices across different execution runtimes (compiled vs. interpreted, async vs. multi-threaded).
2. **Framework Mastery:** Compare backend paradigms across Django (Python), Gin (Go), Express (Node.js), and Laravel (PHP).
3. **Data & Scripting:** Gain proficiency in data wrangling with Jupyter Notebooks while automating tedious tasks using Python scripts.
4. **Code Quality:** Maintain clean commit histories, well-documented code, and structured project layouts across all languages.
5. **Frontend Development:** Backend is nice but most of the time data is gather from a frontend interaction.
